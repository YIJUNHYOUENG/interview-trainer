김지훈 (신입 안드로이드 개발자 지원)
이메일: sample@example.com | GitHub: https://github.com/octocat/Hello-World

[한 줄 소개]
Kotlin으로 앱을 만들고, 서버와 연결해 실제로 동작하는 서비스를 끝까지 완성하는 일을 좋아합니다.

[기술 스택]
- 언어: Kotlin, Java, Python, SQL
- 안드로이드: XML Views, Room, Coroutines, RecyclerView, HttpURLConnection
- 서버: FastAPI, SQLite
- 기타: Git, GitHub, Android Studio

[프로젝트]
1. 개발자 면접 트레이너 (팀 프로젝트, 2026.09 ~ 2026.11, 2인)
- AI 모의 면접과 CS 개념 학습(퀴즈, 오답노트, 복습 주기)을 제공하는 안드로이드 앱
- 담당: CS 개념 학습 화면, 퀴즈 출제 규칙, Room DB 설계와 마이그레이션
- 하루 3문제를 복습일이 된 개념부터 고르는 출제 규칙을 만들고 단위 테스트로 검증
- 퀴즈 답을 저장할 때 진도, 오답, 오늘의 퀴즈를 Room 트랜잭션으로 묶어 일부만 저장되는 문제를 막음
- 성과: 개념 60개, 퀴즈 180문제 콘텐츠를 앱에 내장해 서버 없이도 학습 가능

2. 할 일 관리 앱 (개인 프로젝트, 2026.03 ~ 2026.05)
- 할 일 등록, 완료, 알림 기능이 있는 앱. Room과 LiveData로 목록을 실시간 갱신
- 목록이 길어졌을 때 화면이 끊기는 문제를 DiffUtil로 바꿔 해결

[경험]
- 학교 알고리즘 스터디 (2025.03 ~ 2025.12): 매주 문제 2개를 풀고 풀이를 발표
- 교내 해커톤 참가 (2025.10): 2일 동안 앱 프로토타입을 만들어 발표

[학력]
OO대학교 컴퓨터공학과 졸업 예정 (2027.02)

[자기소개서]
지원 동기: 사용자가 직접 쓰는 앱을 만들 수 있는 안드로이드 개발자가 되고 싶습니다. 팀 프로젝트에서 사용자가 틀린 문제를 다시 풀게 만드는 기능을 만들며, 기능 하나가 화면, 저장, 규칙에 모두 걸쳐 있다는 것을 배웠습니다.
강점: 막히면 원인을 기록하며 좁혀 가는 습관이 있습니다. 음성 인식이 잘 안 되던 문제를 녹음 파일을 직접 저장해 들어 보고, 소리가 처음 2초 동안 안 들어온다는 원인을 찾아 해결했습니다.
보완할 점: 테스트 코드를 처음부터 쓰는 습관이 아직 부족해서, 최근에는 규칙 계산 부분부터 단위 테스트를 먼저 작성하고 있습니다.
